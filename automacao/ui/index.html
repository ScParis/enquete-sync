      💡 Guia Rápido de Destravamento: Os 3 Erros do ValidaPDF (#vocepode G-Click) Clique para ver o checklist e como resolver documentos travados ▾
      1. Modelo Não Encontrado

      A estrutura de linhas mudou (ex.: palavra-chave estava na linha 2 e foi para a 4).

      Solução: Cadastre um modelo adicional dando alternativas A, B, C ao G-Click. Para folha com eventos variáveis, use o Anexo por Nome.
      2. Cliente Não Encontrado (Crítico)

      O CNPJ/CPF não existe no sistema, ou o recibo não tem CNPJ impresso.

      Solução: Cadastre o cliente e gere tarefas. Para recibos sem CNPJ, use Campo Adicional (IE/IM/Código ERP) no cadastro.
      3. Tarefa Não Encontrada

      O modelo e o cliente foram reconhecidos, mas a gaveta da competência não foi gerada.

      Solução: Acesse o cliente ou obrigação e gere a tarefa no G-Click para essa competência.
      ⚡ Folha com Rubricas? Use Anexo por Nome!

      Holerites variam linhas todo mês. Padronize o nome do arquivo para entrega direta sem depender de linhas fixas.

      Padrão: [Obrigação]-[CNPJ]-[Competência].pdf
